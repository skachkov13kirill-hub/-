## ПЛАН — 8 ключевых фич для развития

Подробности: `docs/LEVEL2_STRATEGY.md` и `docs/LEVEL2_1_STRATEGY.md`

### Фича 1: Экран «Аналитика»
Новый экран в нижней навигации. Содержит:
- **Stacked bar** — доли категорий (%) по месяцам
- **Средние траты в день** — бар-чарт: зелёные/красные столбцы + линия среднего
- **Аномалии/всплески** — категории где расход > 1.5× от среднего
- **Топ-15 мерчантов** — за всё время, с прогресс-барами
- **Тренд категории** — график при клике на категорию

### Фича 2: Фильтр по диапазону месяцев
Сейчас только один месяц. Нужно: monthFilter + monthFilterTo, чтобы можно было «с января по март».

### Фича 3: Бюджеты 2.0
Сейчас есть базовый saveBudget. Нужно:
- Прогресс-бары бюджетов прямо на дашборде (красный при превышении, зелёный в норме)
- Карточки «🔴 Превышение» и «🟢 В запасе»
- Авто-расчёт нормы по среднемесячному

### Фича 4: Тренд категории (showCategoryTrendDrill)
При клике на категорию — модалка с линейным графиком расходов по месяцам, со средней линией и нормой.

### Фича 5: Drill-down по месяцам (showMonthBreakdown)
При клике на точку в графике трендов — модалка с разбивкой месяца по категориям.

### Фича 6: Система вёдер
Вместо «Перевод себе» для всего — 3 ведра: транзит (кэшбэк, возврат), бизнес, нераспределённые. С кнопками перемещения.

### Фича 7: Менеджер правил с поиском
Расширить текущий renderRules(). Добавить: поиск, фильтр по типу, массовые операции, добавление правила через форму.

### Фича 8: Google Sheets синхронизация
Двусторонняя синхронизация через Apps Script JSONP. Облачный бэкап.

## СТРУКТУРА КОДА (ключевые функции)

**Навигация** (экраны):
- Dashboard (renderDashboard) — главный экран
- Transactions (renderTransactions) — список операций
- Trends (renderTrends) — графики
- Profile (renderProfile) — настройки, PRO, экспорт

**Парсеры:**
- parseSberPDF() — Сбер
- parseTinkoff() — Тинькофф
- parseCSV() — универсальный CSV

**Категоризация:**
- CATEGORIES — 18 категорий с паттернами
- categorize() — автоматическая
- renderRules() — пользовательские правила

**Уникальные фичи:**
- isPro() / showProModal() / startTrial() — монетизация
- findSubscriptions() / findRecurringPatterns() — подписки
- renderAdvisor() — 5 типов советов
- renderHealth() — health score 0-100
- renderCalendar() — календарь расходов
- renderShock() — shock-факты
- renderStreak() — дни без трат
- getDebts() / renderDebtsSection() — долги
- renderGoals() / addToGoal() — цели накопления
- renderTrash() — корзина (soft delete 30 дней)
- showTutorial() / TUTORIAL_STEPS — онбординг
- showHint() / checkHints() — подсказки
- showWizardMisc() — визард для «Прочее»
- findMatchedTransfer() — сопоставление переводов

**Состояние** (STATE):
- STATE.transactions — массив транзакций
- STATE.rules — пользовательские правила категорий
- STATE.budgets — бюджеты по категориям
- STATE.goals — цели накопления
- STATE.debts — долги
- STATE.trash — корзина
