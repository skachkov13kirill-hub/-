## Фичи для реализации

### 🔴 ПРИОРИТЕТ 1 — Критические для запуска

#### 1. Вкладка «Анализ» (разрезы и тренды)
Новый экран с 5 секциями:
- Структура расходов — stacked bar (доля % каждой категории по месяцам)
- Средние траты в день — бар-чарт с линией среднего
- Аномалии — категории с всплеском >1.5× от среднего
- Топ-15 мерчантов за всё время
- Тренд выбранной категории

**Текущее состояние:** есть только donut + список категорий. Нет глубокой аналитики.

---

#### 2. Система вёдер (Bucket System) — распределение переводов
3 ведра: бизнес / транзит / нераспределённые + кнопки перемещения.
- Правила вёдер запоминаются навсегда
- Визуальная сводка по вёдрам (сетка карточек с суммами)

**Текущее состояние:** есть только «Перевод себе» — нет системы распределения.

---

#### 3. Фильтр по диапазону месяцев
Возможность выбрать «с января по март» вместо одного месяца.

**Текущее состояние:** только один месяц за раз.

---

#### 4. Нормы/бюджеты с визуальным план-факт
- Прогресс-бар с цветовой индикацией (красный при превышении)
- Обзор с топ-5 превышений и экономий
- Два режима: фиксированный и авто-расчёт по среднемесячному

**Текущее состояние:** есть budgets (saveBudget), но только базовый — нет визуального план-факт на дашборде.

---

#### 5. Google Sheets синхронизация (облако)
Двусторонняя синхронизация через Apps Script:
- Загрузка из облака
- Выгрузка в облако
- Умное слияние транзакций

**Текущее состояние:** только localStorage.

---

### 🟡 ПРИОРИТЕТ 2 — Удобные фичи

#### 6. Drill-down модалы на каждом уровне
Добавить:
- Тренд одной категории по месяцам (график)
- Разбивку месяца при клике на график трендов
- Вложенный drill-down (категория → мерчант → операции)

**Текущее состояние:** есть showCategoryDetail и openExpenseDetail, но нет вложенных drill-down.

---

#### 7. Менеджер правил
Полноценный экран:
- Поиск по паттернам
- Фильтр по типу
- Добавление новых правил через форму
- Массовые операции

**Текущее состояние:** есть renderRules(), но только список с удалением, без поиска и фильтров.

---

#### 8. Кастомизация интерфейса
- Цветовые схемы (несколько пресетов + кастом)
- Выбор шрифтов
- Размер шрифта (мал/норм/крупн)

**Текущее состояние:** только тёмная/светлая тема. Не приоритет для MVP.
